AQUARIUMPLANTEN — DATABASE VOOR PLANTEN, VISSEN, METINGEN EN ONDERHOUD
======================================================================

Nederlands staat bovenaan, English staat onderaan.
(The Dutch part is first, the English part is at the bottom.)

Een eenvoudig programma op je eigen computer: geen account, je data blijft
bij je. Werkt op Windows (.exe) en op elke Raspberry Pi / NAS / Linux-server.


SNEL BEGINNEN (niets installeren)
---------------------------------
Nieuwste versie: https://github.com/juant07/Aquarium-Database/releases

Dubbelklik Aquarium.exe. Klaar: de browser opent vanzelf op de app.

Het zwarte venster moet open blijven zolang je de app gebruikt. Sluit je het
venster, dan stopt de app (je data blijft bewaard).

Pak je een zip uit: pak ALTIJD de hele map uit, niet losse bestanden.

Taal: rechtsboven schakel je tussen NL en EN. Je keuze wordt onthouden.

Werkt dit niet? Zie "PROBLEMEN" onderaan.


ZELF EEN EXE MAKEN (alleen met de bronbestanden)
-----------------------------------------------
Staat er een build_exe.bat in de map? Dan kun je zelf een .exe maken.
Nodig: Windows-PC met internet.

1. Installeer Python 3.11 of 3.12 van https://www.python.org/downloads/
   Belangrijk: zet het vinkje "Add python.exe to PATH" aan.
2. Dubbelklik build_exe.bat en wacht op "KLAAR: dist\Aquarium.exe".
3. In de map dist\ staat Aquarium.exe (+ icon.png en manifest.json).
   Dubbelklikken = de app starten; geen Python meer nodig op die PC.
   Gebruik Python 3.11 of 3.12; 3.13 werkt niet met deze app.


DE APP OP JE GSM OF LAPTOP
--------------------------
1. Start de app op de computer in huis. In het zwarte console-venster staan
   twee regels, bv.:

     Planten op http://localhost:8377
     Vanaf je gsm of laptop: http://192.168.1.50:8377

   De tweede regel is precies wat je nodig hebt.
2. Zorg dat je gsm op hetzelfde wifi-netwerk staat als die computer
   (dus niet op mobiel internet / 4G).
3. Typ dat adres in de browser van je gsm en klaar.
4. In de browser: menu -> "Installeren" / "Toevoegen aan startscherm" om de
   app als icoon op je gsm of bureaublad te zetten (PWA).

Je IP-adres zelf opzoeken (als het zwarte venster al dicht is):
  a) Windows: Windows + R, typ cmd, Enter, dan:   ipconfig
     Kijk bij "IPv4-adres" (Engels: "IPv4 Address"), bv. 192.168.1.50.
  b) Windows zonder cmd: Instellingen -> Netwerk & internet -> Eigenschappen
     van je verbinding -> "IPv4-adres".
  c) Mac: Systeeminstellingen -> Netwerk.  Raspberry Pi / Linux: ip a

Dat adres komt van je router (dhcp) en kan na een herstart veranderen. Wil je
het vastzetten, reserveer dan in je router een "vast adres" voor die computer.


JE DATA
-------
Naast plants.py (of Aquarium.exe) staan twee dingen die JIJ bezit:
  plants.db      je hele database
  photos\        de foto's die je hebt toegevoegd

Kopieer die twee af en toe naar een USB-stick of NAS als backup.
Opnieuw beginnen: verwijder plants.db en start de app opnieuw.
Je data blijft op je eigen apparaat. Het programma gaat alleen naar het
internet voor het opzoeken van plant-/visinfo en voor meldingen.


MELDINGEN OP JE GSM (optioneel)
-------------------------------
Zonder configuratie werkt de hele app, alleen komen er geen pushberichten.
Zet naast plants.py (of Aquarium.exe) een bestand notify.json met jouw kanaal.
Zie notify.json.example in deze map. Met "lang": "en" zijn de meldingen Engels.

Optie A — via Home Assistant (als je die al hebt):
  {
    "lang": "nl",
    "ha": {
      "url": "http://192.168.1.10:8123",
      "token": "jouw-long-lived-token",
      "services": ["mobile_app_jouw_toestel"]
    }
  }
  Token maak je in Home Assistant: profiel -> Beveiliging -> Long-lived access
  tokens -> Token aanmaken. Let op: dat token geeft volledige toegang tot je
  Home Assistant. Deel dat bestand dus nooit met iemand anders.

Optie B — via ntfy (gratis, geen account nodig):
  {
    "lang": "nl",
    "ntfy": {"server": "https://ntfy.sh", "topic": "jouw-eigen-onderwerp"}
  }
  Kies een onderwerp dat nog niemand gebruikt (bijv. aquarium-jan).
  Installeer de app "ntfy" op je gsm, kies server ntfy.sh en abonneer je op
  hetzelfde onderwerp.

De app meldt:
  - zodra je een taak toevoegt of afvinkt
  - elke ochtend rond 09:00 met alle taken die te laat zijn


EIGEN SERVER IN PLAATS VAN WINDOWS (optioneel)
-----------------------------------------------
Op een Raspberry Pi, NAS of Linux-server:
  python3 plants.py
en open daarna http://<ip>:8377
Er is geen installatie nodig: het is één bestand (plants.py).

Wil je hem automatisch laten starten (systemd), maak dan
/etc/systemd/system/aquarium.service met:
  [Unit]
  Description=Aquariumplanten
  After=network-online.target
  [Service]
  WorkingDirectory=/opt/aquarium
  ExecStart=/usr/bin/python3 /opt/aquarium/plants.py
  Restart=always
  [Install]
  WantedBy=multi-user.target
Daarna: sudo systemctl enable --now aquarium
(Zet plants.py, icon.png en manifest.json in /opt/aquarium.)


MET DOCKER (Debian, Ubuntu, NAS met Docker)
-------------------------------------------
1. Docker installeren (eenmalig):
     curl -fsSL https://get.docker.com | sudo sh
2. Deze map op de server zetten en daarin:
     mkdir -p data
     docker compose up -d --build
   Sneller kan ook, met het kant-en-klare image:
     docker compose pull && docker compose up -d --no-build
3. Open http://<ip-van-de-server>:8377

Je data (plants.db + photos) staat in de map "data"; die map is je backup.
Bijwerken: nieuwe bestanden eroverheen kopiëren en weer
"docker compose up -d --build". Je data blijft staan.

- Pusht de app niet naar Home Assistant? Gebruik het IP-adres van HA in
  notify.json; namen als homeassistant.local werken niet in een container.
- Zet notify.json in de map "data" (niet ernaast), met chmod 600.
- De tijdzone staat in docker-compose.yml (TZ). Klopt die niet, dan komt de
  ochtendmelding op het verkeerde moment.


PROBLEMEN
---------
- "Windows heeft uw pc beveiligd" / Defender blokkeert:
  rechtsklik op het bestand -> Eigenschappen -> vinkje "Unblock" aan.
- Vanaf de gsm geen verbinding:
  * beide op hetzelfde wifi (niet op 4G),
  * Windows firewall-toestemming voor poort 8377 toestaan,
  * adres met poort gebruiken: http://192.168.1.50:8377
- "Poort 8377 niet beschikbaar": de app draait al. Sluit het andere venster.
- Zwart venster sluit direct: start Aquarium.exe vanuit een terminal
  (cmd) om de melding te lezen, of controleer of de app al draait.

Vragen? Zie de README op https://github.com/juant07/Aquarium-Database

AQUARIUM PLANTS — DATABASE FOR PLANTS, FISH, MEASUREMENTS AND MAINTENANCE
=========================================================================

A simple program on your own computer: no account, your data stays with you.
Works on Windows (.exe) and on any Raspberry Pi / NAS / Linux server.


QUICK START (nothing to install)
--------------------------------
Latest version: https://github.com/juant07/Aquarium-Database/releases

Double-click Aquarium.exe. Done: the browser opens the app automatically.

The black window has to stay open while you use the app. If you close it,
the app stops (your data is kept).

When you unzip: ALWAYS extract the whole folder, not single files.

Language: top right you can switch between NL and EN. Your choice is
remembered.

Not working? See "TROUBLESHOOTING" at the bottom.


BUILDING YOUR OWN EXE (source files only)
-----------------------------------------
Does the folder contain build_exe.bat? Then you can build your own .exe.
Requirements: a Windows PC with internet.

1. Install Python 3.11 or 3.12 from https://www.python.org/downloads/
   Important: tick "Add python.exe to PATH".
2. Double-click build_exe.bat and wait for "KLAAR: dist\Aquarium.exe".
3. The folder dist\ then contains Aquarium.exe (+ icon.png and manifest.json).
   Double-clicking starts the app; Python is no longer needed on that PC.
   Use Python 3.11 or 3.12; 3.13 does not work with this app.


THE APP ON YOUR PHONE OR LAPTOP
-------------------------------
1. Start the app on the computer in your home. The black console window
   shows two lines, for example:

     Planten op http://localhost:8377
     Vanaf je gsm of laptop: http://192.168.1.50:8377

   The second line is exactly what you need.
2. Make sure your phone is on the same wifi network as that computer
   (so not on mobile data / 4G).
3. Type that address in your phone's browser and you're done.
4. In the browser: menu -> "Install" / "Add to home screen" to put the app
   as an icon on your phone or desktop (PWA).

Finding your own IP address (if the black window is already closed):
  a) Windows: Windows + R, type cmd, Enter, then:   ipconfig
     Look for "IPv4 Address", e.g. 192.168.1.50.
  b) Windows without cmd: Settings -> Network & internet -> Properties of
     your connection -> "IPv4 address".
  c) Mac: System Settings -> Network.  Raspberry Pi / Linux: ip a

That address comes from your router (dhcp) and can change after a reboot.
To keep it fixed, reserve a "static address" for that computer in your router.


YOUR DATA
---------
Next to plants.py (or Aquarium.exe) are two things that YOU own:
  plants.db      your entire database
  photos\        the photos you added

Copy those two to a USB stick or NAS now and then as a backup.
Start over: delete plants.db and start the app again.
Your data stays on your own device. The program only goes to the internet to
look up plant/fish information and for notifications.


NOTIFICATIONS ON YOUR PHONE (optional)
--------------------------------------
Everything works without configuration, you just get no push notifications.
Put a notify.json file next to plants.py (or Aquarium.exe) with your channel.
See notify.json.example in this folder. With "lang": "en" the notifications
are in English (default is Dutch).

Option A — via Home Assistant (if you already have it):
  {
    "lang": "en",
    "ha": {
      "url": "http://192.168.1.10:8123",
      "token": "your-long-lived-token",
      "services": ["mobile_app_your_device"]
    }
  }
  Create the token in Home Assistant: profile -> Security -> Long-lived access
  tokens -> Create token. Note: that token gives full access to your Home
  Assistant. Never share that file with anyone else.

Option B — via ntfy (free, no account needed):
  {
    "lang": "en",
    "ntfy": {"server": "https://ntfy.sh", "topic": "your-own-topic"}
  }
  Pick a topic nobody else uses (e.g. aquarium-john).
  Install the "ntfy" app on your phone, choose server ntfy.sh and subscribe
  to the same topic.

The app notifies you:
  - as soon as you add or check off a task
  - every morning around 09:00 with all overdue tasks


YOUR OWN SERVER INSTEAD OF WINDOWS (optional)
---------------------------------------------
On a Raspberry Pi, NAS or Linux server:
  python3 plants.py
and then open http://<ip>:8377
Nothing to install: it is one file (plants.py).

To start it automatically (systemd), create
/etc/systemd/system/aquarium.service with:
  [Unit]
  Description=Aquariumplanten
  After=network-online.target
  [Service]
  WorkingDirectory=/opt/aquarium
  ExecStart=/usr/bin/python3 /opt/aquarium/plants.py
  Restart=always
  [Install]
  WantedBy=multi-user.target
Then: sudo systemctl enable --now aquarium
(Put plants.py, icon.png and manifest.json in /opt/aquarium.)


WITH DOCKER (Debian, Ubuntu, NAS with Docker)
---------------------------------------------
1. Install Docker (once):
     curl -fsSL https://get.docker.com | sudo sh
2. Put this folder on the server and inside it:
     mkdir -p data
     docker compose up -d --build
   Faster, with the prebuilt image:
     docker compose pull && docker compose up -d --no-build
3. Open http://<server-ip>:8377

Your data (plants.db + photos) lives in the "data" folder; that folder is your
backup. Updating: copy the new files over it and run
"docker compose up -d --build" again. Your data is kept.

- Not pushing to Home Assistant? Use the IP address of HA in notify.json;
  names like homeassistant.local do not work inside a container.
- Put notify.json in the "data" folder (not next to it), with chmod 600.
- The time zone is set in docker-compose.yml (TZ). If it is wrong, the morning
  notification arrives at the wrong time.


TROUBLESHOOTING
---------------
- "Windows protected your PC" / Defender blocks it:
  right-click the file -> Properties -> tick "Unblock".
- No connection from the phone:
  * both on the same wifi (not on 4G),
  * allow the Windows firewall permission for port 8377,
  * use the address with the port: http://192.168.1.50:8377
- "Port 8377 not available": the app is already running. Close the other window.
- The black window closes immediately: start Aquarium.exe from a terminal
  (cmd) to read the message, or check whether the app is already running.

Questions? See the README at https://github.com/juant07/Aquarium-Database
